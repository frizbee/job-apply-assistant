# Himalayas: повторные проверки безопасности

## Что подтверждено

Официальный API `/jobs/api/search` доступен без входа: по первому сохранённому
заголовку Senior Ruby on Rails Developer получены 20 записей. Поле description
содержит HTML, а applicationLink в проверенных записях ведёт на страницу
Himalayas с `utm_source=api`, не непосредственно в ATS работодателя.

[Документация API](https://himalayas.app/api) требует использовать applicationLink
без подмены. Поэтому доступность JSON API не означает доступность Apply: если
страница Himalayas показывает challenge, автоматическое заполнение не доказано.
Настройки, ссылки, API-ключи, профиль и fingerprint для обхода не менялись.

## Исправление нашего цикла

Общий детектор ранее распознавал `Verify you are human`, но не формулировку
`Verifying you are human`. Вариант Himalayas теперь считается блокировкой;
также распознаётся `website verifies you are not a bot`.

Если при восстановлении неизвестных метаданных проверка доступа не завершилась,
приложение записывает текущую неопределённую запись обычным защищённым путём и
останавливает **этот источник**, вместо открытия следующей вакансии с новой
проверкой. Если challenge уже открыт по URL текущей вакансии, его содержимое
не принимается за метаданные объявления. Остальные включённые источники могут
продолжиться; успешное ручное завершение проверки по-прежнему позволяет прочитать
метаданные и выполнить остальные проверки.

Сам сайт может повторять challenge во время пассивного ожидания. Изменение
не гарантирует прохождение Cloudflare и не обходит защиту. Источник не следует
считать готовым к LIVE только на основании доступного API.

## Проверка

**675 тестов прошли**, включая 6 новых регрессий: новые тексты challenge,
обычный текст вакансии, одна попытка навигации при блокировке метаданных,
уже открытая challenge-страница, продолжение других источников и успешная
ручная проверка. Для тестов отправки использованы заглушки, живые формы
Himalayas не открывались и заявки не отправлялись.

Для применения остановить текущий прогон и перезапустить GUI. Очередь,
история, предпочтения и Test mode не сбрасываются.

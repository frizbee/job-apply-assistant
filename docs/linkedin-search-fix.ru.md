# LinkedIn: выдача SDUI и проверка региона

## Причина и изменение

Новая выдача LinkedIn хранит ID карточек в `componentkey="job-card-component-ref-…"`.
Старый сборщик пропускал их и находил ссылки только на выбранную вакансию.
Кроме того, переход по старому URL с текстовым `location` терял регион:
North America и Europe фактически показывали Greater Buenos Aires.

`linkedin_search.py` собирает уникальные ID внутри контейнера выдачи, ждёт
гидратацию, прокручивает список и использует настоящий Next вместо правила
«меньше 25 карточек — последняя страница». Поиск живёт в отдельной вкладке,
поэтому открытие вакансии не уничтожает состояние пагинации. Повтор страницы
останавливает обход.

Регион разрешается только через точное совпадение с вариантом нативного
автодополнения LinkedIn. Полученный `geoId`, подпись региона, ключевые слова
и временной фильтр проверяются после перехода и сбора. Remote и Easy Apply
применяются через нативные переключатели. Несовпадения блокируют обработку
результатов; проверенные и неуспешные поиски учитываются раздельно.

Настройки пользователя, CV и история не изменяются. Другие адаптеры не менялись.
Чтение описания LinkedIn дополнительно ждёт его появления, даже если название
и компания уже загрузились: иначе возникал ложный `stack_unknown`.

## Живая проверка 2026-10-22

- Latin America: подтверждённый регион, 25 ID на первой и 25 на второй странице.
- С включённым Easy Apply первый сохранённый запрос дал 18 карточек.
- North America: точного варианта автодополнения не найдено.
- Europe: предложены European Union, European Economic Area и EMEA,
  но точного Europe нет. Эти варианты автоматически не выбираются.
- Поэтому текущие North America и Europe явно пропускаются с объяснением,
  а не заменяются другими регионами. Для них пользователь должен выбрать
  поддерживаемое название; настройки автоматически не исправляются.

## Проверка Easy Apply без отправки

Открыта реальная форма Full Stack Engineer — AllianceIT Inc, LinkedIn ID
`4481142549`, remote из LATAM. Использованы принудительный test mode,
отключённая реализация финальной отправки и изолированная копия истории.

Форма остановлена в `manual_review`: обязательные Mobile phone number,
Email address и Phone country code не подтверждены. Предзаполненный телефон
не совпал с подтверждённым ответом профиля; email и код страны не сопоставились
с вариантами списков. Значения не подменялись, защита не ослаблялась.
Событий заполнения — 0, preview — 0, отправок — 0.
Контрольные суммы рабочих настроек, истории и журналов не изменились.

Это подтверждает открытие формы, но **не успешное заполнение** и не готовность
к автоматической реальной отправке. Требуется отдельная проверка контактов.
Наличие Ruby в описании также не подтверждает полное соответствие кандидата.

Приватные HTML, скриншоты и отчёты находятся в игнорируемом каталоге
`data/browser-diagnostics/linkedin-search-fix-20261022T224638Z/`.

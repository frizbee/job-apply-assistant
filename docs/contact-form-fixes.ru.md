# Контакты, динамические формы и подтверждённые ответы

## Контакты

Добавлено распознавание стандартных имени, фамилии, email, телефона и кода
страны для LinkedIn, а не только внешних ATS. Email выбирается по точному
совпадению; код страны — по отдельному подтверждённому коду. Если один код
соответствует нескольким вариантам, страна проживания не используется как
догадка. Телефон сравнивается без пробелов, скобок и дефисов, но цифры должны
совпадать. Дополнительная цифра — не форматирование.

Новая опция GUI **Replace site-prefilled name, email and phone…** по умолчанию
выключена. Включать её следует только после проверки профиля: она разрешает
заменять отличающиеся предзаполненные контакты подтверждёнными значениями.
Другие ответы опция не меняет. При смене CV разрешение сбрасывается.

Для React-select проверяется выбранное значение конкретного контрола:
поисковый input после выбора может быть пустым. Нативные select повторно
проверяются перед preview/отправкой. Greenhouse-контрол Country рядом с
телефоном распознаётся отдельно как выбор телефонного кода, а не как
подтверждение национальности или права на работу.

## Greenhouse

В живой проверке воспроизведено смещение file-input после загрузки CV:
старый `.nth(1)` ждал уже исчезнувшее поле. Также обнаружены служебные
`aria-hidden=true` inputs React, которые ошибочно считались обычными полями.

Теперь используется уникальный ID поля либо токен конкретного DOM-узла;
текст вопроса проверяется повторно. Загрузка CV не должна сместить указатель
на cover letter, а уже выбранный тот же файл не загружается повторно.
Служебные inputs исключены из заполнения, но не из проверки обязательности.

При перестройке формы допустим один повторный осмотр того же проверенного
документа. Переход, reload, чужой сайт или небезопасный form action остаются
блокирующими. Повторный осмотр не повторяет финальный Submit.

## 10 шаблонов вопросов

В GUI добавлены редактируемые пары «вопрос / подтверждённый ответ»:
национальность, право на работу, sponsorship, on-call, недавнее достижение,
мотивация, знакомые в компании, accessibility, neurodiversity, relocation.
Это стартовый список, а не статистический рейтинг частоты вопросов.

Все ответы изначально пустые. Текст вопроса можно заменить на точную
формулировку работодателя; регистр, пробелы и завершающий `*` несущественны.
Условия страны, компании, сроки и отрицания не удаляются при сопоставлении.
Ответы сохраняются с SHA-256 текущего CV и не наследуются новым CV.
Юридические ответы не выводятся из места проживания; универсального Yes нет.

## Проверки

- **537 тестов успешно**, включая локальные browser-фикстуры контактов,
  явной замены prefill, React-select, скрытых validation proxies, смещения
  file-input, ограниченного повторного осмотра и запрета доверять новому документу.
- Живая Easy Apply AllianceIT `4481142549`: email и код страны перестали
  блокировать форму. Телефон LinkedIn содержит дополнительную цифру перед
  сохранённым локальным номером: сохранён `manual_review`, значение не подменено.
- Живые формы Alpaca `6207266004` и QuintoAndar `4117067009`: после исправления
  указателей/служебных inputs обе завершились `manual_review` без TimeoutError.
  Неизвестные ответы и неподтверждённые дополнительные поля остались блокерами.
- Проверки React-select для телефонного кода дополнительно пройдены на локальной
  HTML-фикстуре; это не подтверждение завершения соответствующей живой заявки.
- Финальная отправка в диагностике отключена; submit attempts — **0**.
  Контрольные суммы рабочих настроек, истории и журналов не изменились.

Приватные отчёты и HTML находятся в игнорируемых каталогах
`data/browser-diagnostics/contacts-fix-20261023T002534Z/` и
`data/browser-diagnostics/greenhouse-fix-20261023T003145Z/`.

Полного живого preview пока нет. После проверки телефона и заполнения шаблонов
нужен ограниченный Test mode прогон одной формы, не массовая реальная отправка.
Фильтрация ограничений BRAZIL ONLY в этой задаче не добавлялась.
